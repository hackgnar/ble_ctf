## Flag 29 Hint

Read handle 0x006d.  Then read it again.

A GATT value is whatever the server decides to hand you at that moment, not a
fixed property of the handle.  This one gives you half the flag per read and
swaps which half comes next.  Read it twice and join the two pieces.

If you have already poked this handle a few times you may get the halves the
other way round.  Either order is accepted.
